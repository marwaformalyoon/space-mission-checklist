# Space Mission Checklist

## Project Idea
A simple webpage for organizing space mission preparation tasks. Users can tick off completed tasks, view their progress, and reset the checklist.

## How It Helps NASA/Space
This project demonstrates how a checklist can help organize mission preparation and track outstanding tasks.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub for version control and project planning

## How to Run
1. Download and extract the project ZIP file.
2. Open index.html in your browser.
3. Tick completed tasks or click Reset to start again.
